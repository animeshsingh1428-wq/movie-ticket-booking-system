Movie Ticket Booking System

Problem Statement

Booking movie tickets manually can be time-consuming and may cause problems such as long queues, seat confusion, and difficulty in checking available shows. The Movie Ticket Booking System is a simple Python-based application designed to make the process of viewing movies, selecting shows, choosing seats, and booking tickets easier and more organized.

Scope of the Project

The project focuses on providing a basic movie ticket booking system using Python. Users can view available movies and show timings, select a movie and show, choose the number of seats, calculate the total ticket price, and confirm their booking. The system can be operated through a simple terminal-based interface.

Target Users

- Movie customers who want to book tickets easily.
- Cinema staff for managing basic booking information.
- Students learning Python programming and developing a practical project.
- Small cinema halls that need a simple ticket booking solution.

High-Level Features

- Display available movies.
- Display available show timings.
- Allow users to select a movie and show.
- Allow users to select seats.
- Check seat availability.
- Calculate the total ticket price.
- Confirm and display booking details.
- Generate a simple booking summary.
- Provide an easy-to-use menu-driven interface.
